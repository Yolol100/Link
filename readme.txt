Contributors: jouw-naam
Tags: internal links, keywords, seo, automatic links
Requires at least: 5.0
Tested up to: 6.5
Stable tag: 1.3

Eenvoudig keywords koppelen aan interne of externe URLs. Automatisch linken in je content.

== Features ==
* Simpele beheerpagina voor keywords en URLs.
* Slechts 1 automatische link per blok buiten bestaande links.
* Makkelijk uit te breiden.

== Installation ==
1. Upload de map `super-simple-internal-links` naar `/wp-content/plugins/`.
2. Activeer de plugin via het WordPress admin menu.
3. Ga naar 'Interne Links' in het menu.
